# Sapientia

Plataforma educativa y de divulgación del conocimiento (sistema visual Steep).

## Publicar en GitHub Pages
1. Crea un repositorio y sube estos archivos a la raíz: `index.html`, `og.jpg`, `.nojekyll`, `README.md`.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. Sustituye `G-XXXXXXXXXX` por tu ID real de GA4 (2 lugares en el `<head>`).
4. Ajusta la URL canónica y de `og:image` si tu dirección final es distinta.

Todo el progreso del usuario se guarda solo en su navegador (`localStorage`).
